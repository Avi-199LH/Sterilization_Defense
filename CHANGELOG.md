# Changelog

All notable changes to this project are documented here.

## [1.0.0] - 2026-10-26

### Added
- Tower-defense gameplay about sterilization and microbial control
- Three modes (Quick, Medium, Long) with up to three tunnels
- Automatic waves with prep timer and wave timer
- Six defenses and eight microbe types, including a prion boss
- Seven themes: Desert, Mario, Covid, Zombie, Mono, Space, Ocean
- Phone and PC layouts, Pixel and Smooth graphics
- Sound, music, particles, screen shake, first-time tutorial
- Upgrades, kill combos, perfect-wave bonus, local best score
- Saved settings, Home button, auto-pause when the tab is hidden

# Contributing

Thanks for your interest in Sterilization Defense!

## Ways to help
- Report bugs or confusing moments using the issue templates
- Suggest new microbes, defenses, themes or levels
- Fix typos or improve the science explanations
- Test on different phones and browsers

## Making a change
1. Fork the repository and create a branch: `git checkout -b my-change`
2. Edit `index.html` (the whole game lives in this one file)
3. Open it in a browser and play a full game to check nothing broke
4. Test both the Phone and PC screen options
5. Commit with a clear message and open a pull request describing what you changed and why

## Guidelines
- Keep the game dependency-free and working offline
- Keep the science accurate; cite a textbook for new facts
- Keep it playable on small phone screens
